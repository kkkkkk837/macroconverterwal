MACRO CONVERTER

Convert Geometry Dash macros between GDR, GDR2, CML and Astral. Pick the format you want, then select as many files as you like. The input format is detected for you, and files never leave your device.

CONVERT TO
.gdr, .gdr2, .cml or .ast, select many at once or drop them here
CML v7 is read and written, and was checked byte for byte against a real xdBot macro. Every result is read back and compared with the original before it is accepted, and one bad file never stops the rest. Frame fixes are kept whenever the format you pick can store them (GDR and CML); GDR2 and Astral can’t, so they are left out there, and the file list says so. Astral (.ast) is read and written, but only for clicks: it carries no author or level info, and 2 player or extra-button clicks aren’t supported yet. Older CML versions (1 to 6) are read for clicks only and are untested. Several files are bundled into one zip.
